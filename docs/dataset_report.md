## Methods

- **Collect** (`src/data/collect.py`): verifies `raw_data_path` exists,
  loads each JSONL line (blank lines tolerated, malformed JSON raises).
- **Clean** (`src/data/clean.py`): collapses whitespace in
  question/context/answer; drops records with empty question or answer;
  sets language to `hi` when Devanagari script is detected (otherwise keeps
  the value, defaulting to `en`); lowercases crop; guarantees all 16 fields
  exist (missing filled with `""`).
- **Deduplicate** (`src/data/deduplicate.py`): pass 1 drops exact duplicates
  on normalized question (keep-first); pass 2 drops records whose question
  token-Jaccard similarity is ≥ `dedup_similarity_threshold` (0.85) with a
  kept record (keep-first). Tokenizer is Unicode-aware (whitespace split +
  edge-punctuation strip) so Devanagari text is compared correctly; the
  previous ASCII-only tokenizer is retired.
- **Splits** (`src/data/splits.py`): seeded shuffle, stratified by
  (topic, language) with ~15% test / ~15% val per stratum and at least one
  record per stratum in train. Leakage guard moves any val/test record with
  question Jaccard ≥ 0.85 against any train record back to train.
- Config values used: `seed=42`, `test_size=0.15`, `val_size=0.15`,
  `dedup_similarity_threshold=0.85`.

## Notes / caveats

- The Hindi subset (48 records, 16.3%) was rewritten during development
  after an early ASCII-only dedup pass wrongly removed templated Hindi
  records; the rewritten set has max pairwise question Jaccard 0.304.
- This is a synthetic seed sample (`source=curated_sample`,
  `source_type=synthetic_seed`), not the closed competition's data. It is
  suitable for pipeline development and CPU smoke tests, not as a claim of
  production training-data quality.
- Full per-record details and the run's JSON stats are in
  `data/processed/dataset_stats.json`.
