What this system does

Retrieval-grounded answers

Every answer is composed from retrieved knowledge-base records with source attribution — never invented from thin air.

Climate context

Weather context is attached to advisories. A mock provider ships by default; a live Open-Meteo provider can be enabled.

Safety first

Exact pesticide/fertilizer dosages are withheld without crop, formulation, region, and authoritative guidance. All 11 safety checks pass.

Private accounts

Salted PBKDF2 password hashing, expiring sessions, and a personal advisory history per user.
